Vector databases are a new-ish specialized form of database, used in AI and Machine Learning.  At the core, a vector database stores length-n vectors of floating point numbers, which are vectors in an n-dimensional space.  Each vector represents a data point.  Another part of the system will store two hash tables, mapping each direction between a vector and the data it represents.  Each of the n dimensions represents one of the features used internally by the AI system to describe the data.

So, a vector is basically a tuple, but there are no primary keys.  There is also no notion of foreign keys or even that tables are connected in any way.

Searching and indexing are important for efficiency, but here they are based upon finding a "nearest" match (by some measure), rather than finding an exact match or a range.  Finding exact nearest neighbors is generally considered too slow, so instead, this is typically implemented with an approximate nearest neighbors algorithm. 

There are multiple algorithms for computing approximate nearest neighbors, but one common technique is with kd-trees.  Kd-trees are balanced trees, where each node is a subset of the overall n-dimensional space.
